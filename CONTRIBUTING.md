# Contributing

Thank you for your interest in Engineering Portfolio. This repository is in the architecture and planning phase.

## Guidelines

- Keep examples fictional and synthetic.
- Do not add proprietary code, data, logs, schemas, or internal names.
- Discuss major architecture choices through ADRs.
- Keep changes focused and documented.
- Add tests and validation evidence when implementation begins.

## Pull Requests

Pull requests should explain the problem, summarize the change, list validation performed, and call out any security or reliability impact.
